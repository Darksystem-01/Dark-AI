# Dark-AI 🌌

Dark-AI is a lightning-fast, premium AI assistant built for the modern web. It features a stunning glassmorphism UI, seamless multilingual support, and the ability to generate images on demand.

Designed specifically to be deployed effortlessly on **Vercel** with zero configuration required.

## ✨ Xususiyatlari (Features)

- **Tezkor Javoblar (Lightning Fast):** O'ta tezkor sun'iy intellekt modeli bilan bir zumda muloqot.
- **Rasm Yaratish (Image Generation):** Matn orqali istalgan turdagi rasmlarni generatsiya qilish imkoniyati.
- **Ko'p Tilli (Multilingual):** Qaysi tilda yozsangiz, AI xuddi shu tilda (jumladan O'zbek tilida ham) bexato va ravon javob qaytaradi.
- **Premium Dizayn (Dark Mode UI):** Zamonaviy va ko'zga yoqimli "Glassmorphism" uslubidagi qorong'i interfeys va chiroyli animatsiyalar.
- **Tarix Saqlanishi (Persistent Memory):** Barcha suhbatlar brauzer xotirasida (localStorage) saqlanib qoladi.
- **API Kalitlarsiz (No API Keys Required):** Hech qanday to'lov yoki ochiq API kalitlarini talab qilmaydi.
- **Vercel uchun Tayyor:** Faqatgina kodlarni GitHubga yuklab Vercelga ulash kifoya.

## 🚀 Qanday qilib ishga tushiriladi (Deployment)

Loyihani **Vercel** orqali internetga chiqarish juda oson:

1. Ushbu loyihani o'zingizning GitHub profilingizga yuklang (ushbu README fayli ham qolgan barcha papkalar bilan birga asosiy qismda bo'lishi kerak).
2. [Vercel.com](https://vercel.com/) saytiga kiring.
3. **Add New Project** tugmasini bosing va o'z GitHub loyihanigizni (Reponi) tanlang.
4. Hech narsani o'zgartirmasdan **Deploy** tugmasini bosing.
5. Tayyor! Vercel sizga saytingizning ssilkasini beradi.
